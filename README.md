
# CurrencyExchangeSystem

Автоматизированная система управления пунктом обмена валют.

## О проекте

Настольное приложение для автоматизации работы пункта обмена валют. Программа позволяет управлять курсами валют, контролировать остатки денежных средств, оформлять обменные операции и просматривать историю.

## Технологии

- C#
- .NET 10
- Avalonia UI 12.1.6
- SQLite
- Microsoft.Data.Sqlite
- CommunityToolkit.Mvvm

## Основные возможности

- Главная панель со статистикой.
- Просмотр и редактирование курсов валют.
- Автоматический расчёт суммы обмена.
- Проверка наличия валюты в кассе.
- Автоматическое изменение кассовых остатков.
- Сохранение истории операций.
- Поиск по истории операций.

## Поддерживаемые платформы

- macOS x64
- Windows x64

## Запуск исходного проекта

1. Установить .NET 10 SDK.
2. Открыть CurrencyExchangeSystem.csproj в IDE.
3. Восстановить NuGet-пакеты.
4. Собрать и запустить проект.

Команды:

```bash
dotnet restore
dotnet build
dotnet run
```

## База данных

Используется SQLite.

База данных создаётся автоматически при первом запуске приложения. Начальные данные включают валюты KGS, USD, EUR и RUB.

## Windows-версия

Готовая Windows x64 версия размещается в разделе GitHub Releases.

Скачайте ZIP-архив, распакуйте его и запустите CurrencyExchangeSystem.exe.
